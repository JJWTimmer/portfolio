# Jasper Timmer — Portfolio

Personal portfolio of Jasper Timmer MSc (Solution Architect & Tech Lead). Built with Next.js App Router, Tailwind CSS, and TypeScript.

Configured as a **static export** (`output: 'export'`) deployed automatically to GitHub Pages at [jaspertimmer.nl](https://jaspertimmer.nl).

## Features

- **Static Export**: Prerendered HTML/CSS/JS with zero server runtime overhead.
- **Single Source of Truth**: All page content (profile, skills, employers, projects, education, certifications, and activities) is centrally typed in `lib/data.ts`.
- **Client-Side Email Obfuscation**: Email address is base64-encoded and decoded client-side via `useSyncExternalStore` so plaintext never leaks into static HTML.
- **Accessible Design**: Semantic HTML5 headings (`h1`, `h2`, `h3`), high-contrast dark theme, and `prefers-reduced-motion` support for animations.
- **Dual Build Workflow**: Next.js builds the static web application to `out/`, while `tsup` compiles reusable components to `dist/` for design-sync tooling.

## Quick Start

```bash
# Install dependencies
npm ci

# Start development server
npm run dev

# Run ESLint check
npm run lint

# Check TypeScript types
npx tsc --noEmit

# Production static export (outputs to out/)
npm run build

# Serve static export locally
npm start

# Build design-sync component bundle (outputs to dist/)
npm run build:components
```

## Project Structure

```
├── app/
│   ├── layout.tsx       # Root layout, metadata, OpenGraph tags, font loading & analytics
│   ├── page.tsx         # Main portfolio page composition (Server Component)
│   └── globals.css      # Tailwind directives, keyframes, blueprint-grid
├── components/          # Reusable UI components (Hero, NavHeader, SkillTile, etc.)
│   └── index.ts         # Component barrel export for tsup build
├── lib/
│   ├── data.ts          # Central data source (skills, experience, projects, etc.)
│   └── useDecodedEmail.ts # Client hydration hook for obfuscated email
├── public/              # Static assets (images, CNAME)
├── .github/workflows/   # GitHub Actions CI/CD deployment pipeline
├── tsup.config.ts       # Config for packaging components to dist/
└── next.config.mjs      # Next.js static export configuration
```

## Deployment

Deployments are automated via GitHub Actions on push to `main` (`.github/workflows/deploy.yml`). The static bundle generated by `npm run build` is published directly to GitHub Pages.
